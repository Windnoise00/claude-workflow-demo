Helpdesk tickets, names, emails and anything about students or staff never go into a hosted model.

**Why:** data protection; the AI provider is a third party.

**How to apply:** the work knowledge base holds generic fixes ("Teams won't sign in after password reset"), written by hand from patterns, never pasted tickets.
